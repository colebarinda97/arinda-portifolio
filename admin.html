Backup & publishing

Export for website to download portfolio-content.json, then replace docs/portfolio-content.json and push to GitHub. Keep a separate backup if you want to transfer your editor settings to another browser.

Admin changes are saved only in this browser. Export for website does not automatically publish. Do not place these admin files in the public docs folder: this editor has no authentication.
